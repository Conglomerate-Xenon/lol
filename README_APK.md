# Сборка APK без Android Studio

Это тот же веб-debug launcher, но подготовленный для упаковки в Android APK через Capacitor.

## Самый простой способ

1. Создайте пустой GitHub-репозиторий.
2. Загрузите содержимое этого проекта в репозиторий.
3. Откройте вкладку **Actions**.
4. Запустите workflow **Build Android APK**.
5. После завершения откройте выполненный workflow и скачайте artifact `dead-ahead-debug-apk`.
6. Внутри будет `app-debug.apk`.

Android Studio на вашем ПК не нужен: сборка выполняется на GitHub runner.

## Что делает APK

- открывает debug-панель;
- показывает тестовые валюты;
- кнопка `+1000 ко всем` изменяет только локальное состояние панели;
- данные сохраняются через localStorage;
- это не внедрение в процесс установленной игры и не изменение памяти игры.

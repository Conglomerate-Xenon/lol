# Dead Ahead Debug Web

Тестовая веб-панель экономики. Она НЕ изменяет процесс установленной игры.

## Запуск
Откройте `index.html` в браузере.

## Что есть
- тестовые значения валют;
- +1000 ко всем;
- сброс;
- localStorage;
- журнал операций.

Для APK нужен WebView/Capacitor wrapper или облачная сборка. Нативный launcher не получает доступ к памяти другого приложения.
